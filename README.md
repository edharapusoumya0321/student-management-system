# Student Management System

## Project Description
The Student Management System is a console-based Java application that helps manage student records. It uses ArrayList to store student information and file handling to save records.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Eclipse IDE

## Features
- Add new student records
- Display all students
- Search for a student by ID
- Update student details
- Delete student records
- Calculate average grades
- Save and load student records using file handling

## Project Structure
- `Main.java` – Runs the application and displays the menu.
- `Student.java` – Stores student details.
- `StudentManager.java` – Handles student management operations.

## How to Run
1. Download or clone this repository.
2. Open the project in Eclipse IDE.
3. Run `Main.java`.
4. Follow the menu displayed in the console.
